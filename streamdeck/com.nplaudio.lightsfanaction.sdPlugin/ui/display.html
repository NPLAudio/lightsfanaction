About this key

Drop it on any key. Every display key on the same deck shows its own part of one picture, placed by its column and row, so the keys act like one screen. The picture is Lights Fan Action's lighting for this deck: the deck shows up in the app's lighting list, where you choose its effect, how much detail it has, how fast it updates, and the gap between keys.

Keys that do not carry this action are never changed. Image size applies to all display keys; a larger size looks sharper but is more work for the Stream Deck software.
About the test pattern

With the test pattern on, the display keys ignore the app and draw a pattern here, using the rate, detail and gap above. It is for checking how your deck handles frames.
